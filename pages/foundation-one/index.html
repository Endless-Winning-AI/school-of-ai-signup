10 min

Live Setup — Building Your Workshop

Follow along or watch — either way, you'll have this set up before our next session. Tap each step for details.

1

Get a Claude Pro or Max account

Claude Code requires a paid Anthropic account. Go to claude.ai and sign up for Pro ($20/mo) or Max ($100/mo).

→ Sign up at claude.ai
2

Install Node.js

Claude Code runs on Node.js — you need to install it first.

Mac + Windows

Go to nodejs.org, click the big green LTS button, and run the installer. Follow the prompts — the defaults are fine.

To verify it installed, open a terminal and type: node --version — you should see a version number.

3

Install Claude Code

Open a terminal and paste this command:

Mac

Open Terminal (search "Terminal" in Spotlight or find it in Applications → Utilities)

npm install -g @anthropic-ai/claude-code

Windows

Open PowerShell (search "PowerShell" in the Start menu)

npm install -g @anthropic-ai/claude-code

This installs Claude Code globally on your computer so you can use it from any folder.

4

Download an IDE

Pick one and download it. They all work with Claude Code.

Zed Fast, lightweight, built for AI (Mac only) Antigravity AI-native IDE, designed for agents Cursor AI-first code editor (Mac + Windows) VS Code Free, widely used (Mac + Windows)
5

Open a folder and run Claude Code

In your IDE, go to File → Open Folder and pick any folder on your computer — documents, notes, anything. You don't need code.

Then open the terminal inside your IDE and type:

claude

That's it. Claude Code is now running and can see everything in your folder.

How to open the terminal

Mac: In most IDEs, press Ctrl + ` (backtick) or go to View → Terminal

Windows: Same shortcut — Ctrl + ` or View → Terminal

6

Your first prompt

Once Claude is running, try typing:

What files are in this folder and what are they about?

Claude will read through your files and give you a summary. Then try:

Organize these files into folders by topic and rename them

You'll see Claude read each file, create folders, and move things around — all from one sentence.

10 min

What Are Claude Skills?

A skill is a set of instructions you write down so Claude can repeat a complex task without you explaining every step.

→

Without a skill

"Go to this website, copy the text, rewrite it for Instagram, make it 150 characters, add hashtags from this list, save it to this folder..."

→

With a skill

"/create-social-post" — one command, same result every time.

The Recipe Analogy

You don't explain how to make cookies every time. You write the recipe once, and hand it to whoever's baking. Skills work the same way.

8 min

How Skills Work

A skill is just a text file with instructions. When you type a command, Claude reads it and follows it step by step.

1

You type a command

/my-skill-name

2

Claude reads the instructions

The recipe you wrote ahead of time

3

Claude executes each step

Reading files, writing content, running commands

4

You get the result

Consistent output, every time

7 min

Spotting Skill Opportunities

If you find yourself explaining the same thing to AI more than twice, that's a skill waiting to be built.

Signal

"I keep telling Claude the same thing..."

If you're repeating instructions → that's a skill

Signal

"This takes me 10 steps every time..."

If there's a repeatable process → that's a skill

Signal

"I wish I could just press a button..."

If you want one-click automation → that's a skill

Examples by Industry

Real Estate → /generate-listing from photos + details

Marketing → /create-social-post from blog article

Finance → /categorize-transactions from bank CSV

Church → /publish-sermon-notes from transcript

Coaching → /write-followup-email from session notes
